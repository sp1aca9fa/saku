- 2026-10-26 (Tora model): Saku is built like the owner's app Tora. A closed, self-hosted app for a few accounts (a family), one or more admins, no sign-up page, no public pages or public demo; a demo account with the same security as any account. Supersedes the single-owner hosted model, Supabase (Postgres, Auth, RLS), Vercel and GitHub Actions jobs: SQLite via libSQL + Drizzle with add-only migrations, own auth (password + TOTP + backup codes, 2 devices per account, CLI first user, admin-managed accounts), per-user scoping in the query layer with wrong-user tests, systemd timers on the admin's machine, Tailscale Funnel (the owner: port 3001 published on 8443), daily backups copied off the machine. Reason: the owner already runs and trusts this setup; it removes free-tier limits and the market-data-in-public-repo problem.
